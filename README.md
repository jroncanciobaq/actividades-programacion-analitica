# 🐍 Fundamentos de Python

Repositorio dedicado a la práctica y aprendizaje de los fundamentos del lenguaje de programación **Python**.

Aquí se encuentran diferentes ejercicios desarrollados para fortalecer la lógica de programación, comprender la sintaxis de Python y familiarizarme con las principales estructuras y herramientas del lenguaje.

> 📚 Este repositorio documenta mi proceso de aprendizaje mediante ejercicios prácticos y resolución de problemas.

---

## 🎯 Objetivos

Los principales objetivos de este repositorio son:

- Comprender los fundamentos de Python.
- Fortalecer la lógica de programación.
- Practicar la resolución de problemas mediante código.
- Familiarizarme con la sintaxis de Python.
- Comprender el funcionamiento de estructuras de control.
- Desarrollar buenos hábitos de programación.
- Registrar y visualizar mi progreso durante el aprendizaje.

---

## 📚 Contenido

Los ejercicios están organizados por temas para facilitar la consulta y el seguimiento del aprendizaje.

### 1. Variables y tipos de datos

Ejercicios relacionados con:

- Variables
- `int`
- `float`
- `str`
- `bool`
- Conversión de tipos
- Entrada y salida de datos

### 2. Operadores

Práctica de:

- Operadores aritméticos
- Operadores de comparación
- Operadores lógicos
- Operadores de asignación

### 3. Estructuras condicionales

Ejercicios utilizando:

- `if`
- `elif`
- `else`
- Condiciones simples
- Condiciones anidadas
- Operadores lógicos

### 4. Ciclos

Práctica de estructuras repetitivas:

- `while`
- `for`
- Contadores
- Acumuladores
- Control de ciclos
- `break`
- `continue`

### 5. Listas y estructuras de datos

Ejercicios relacionados con:

- Listas
- Índices
- Recorridos
- Métodos de listas
- Tuplas
- Diccionarios
- Conjuntos

### 6. Funciones

Práctica de:

- Definición de funciones
- Parámetros
- Argumentos
- Valores de retorno
- Funciones con diferentes tipos de parámetros

### 7. Cadenas de texto

Ejercicios de:

- Manipulación de strings
- Métodos de cadenas
- Indexación
- Slicing
- Formateo de texto

### 8. Ejercicios de lógica

Problemas diseñados para combinar diferentes conceptos y fortalecer la capacidad de análisis y resolución de problemas.
